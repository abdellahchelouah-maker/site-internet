# Comprendre le fonctionnement d’Internet — AC2026

## Version web allégée

Cette version transforme le support de diapositives en parcours pédagogique continu. Les répétitions dues à la mise en page du diaporama sont supprimées : titres d’activité répétés, consignes identiques sur plusieurs diapositives, illustrations identiques réaffichées plusieurs fois et sommaire final redondant.

### Principes conservés
- contenu pédagogique unique du document source ;
- ordre des activités et des notions ;
- illustrations graphiques originales extraites individuellement du document source ;
- questions et réponses masquées par défaut ;
- maximum de deux colonnes pour le texte sur grand écran ;
- illustrations suffisamment grandes et isolées lorsque nécessaire ;
- navigation entre les huit activités ;
- organisation Apple-like sobre, claire et responsive.

### Organisation
- `index.html` : accueil, couverture, sommaire et introduction historique ;
- `pages-web/activity-1.html` à `activity-8.html` : parcours des huit activités ;
- `css/style.css` : charte graphique et mise en page ;
- `js/main.js` : réponses et navigation active ;
- `images/illustrations/` : illustrations originales uniques du document source ;
- `videos/` : emplacement réservé aux vidéos.

### Choix de simplification
Le sommaire final redondant du document source n’est pas reproduit. Les éléments répétés à l’identique sur plusieurs diapositives sont regroupés dans une seule section, tandis que les informations nouvelles apparaissent à leur emplacement pédagogique.
